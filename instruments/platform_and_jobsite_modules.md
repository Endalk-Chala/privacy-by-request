# Platform-use and job-site modules

Both modules are administered after the timeline and before the exposure audit. The participant operates their own device; the investigator never logs in to a participant's account or handles the device.

## Platform-use module (Platform_Use sheet)

| Variable | Wording or procedure | Code |
|---|---|---|
| Facebook, WhatsApp, TikTok, Telegram, YouTube, Instagram | "Which of these do you use at least weekly?" | 0/1 each |
| Other platforms | count of other platforms named | number |
| hours_per_day | "On a normal day, about how many hours do you spend on all of these together?" | 0 to 16 |
| location_services_on | "Is location turned on for any of these apps?" | 0/1/unsure→0 |
| contacts_uploaded | "Did any of these apps ask to see your phone contacts, and did you allow it?" | 0/1 |
| posts_family_photos | "Do you post photos of family members?" | 0/1 |
| in_community_groups | "Are you in groups for people from your community or home region?" | 0/1 |
| imagined_audience_platforms | "When you post, who do you picture seeing it?" | Family and community / Friends / Everyone / Employers / Government / Nobody in particular |
| off_facebook_activity_count | Optional consented walkthrough: the participant opens Settings → Your information → Off-Facebook Activity (or the current equivalent) on their own device and reads out the number of apps and websites listed. | number, or blank if declined |
| ad_interest_immigration_related | In the same walkthrough, whether the ad-interest list includes immigration-, remittance- or home-country-related categories | 0/1, blank if declined |
| reaction_to_platform_lookup | dominant reaction to the walkthrough | Surprise / Fear / Resignation / Anger / Indifference / Already knew |

## Job-site module (Job_Sites sheet)

| Variable | Wording or procedure | Code |
|---|---|---|
| posted_resume_online | "Have you ever uploaded a résumé to a job website?" | 0/1 |
| sites_used | count named | number |
| resume_public | Checked with the participant in their own account: is the résumé set to public or searchable on at least one site? | 0/1 |
| full_address_on_resume, personal_phone_on_resume, foreign_education_listed, license_number_on_resume, references_listed | What the résumé carries (participant shows or recalls) | 0/1 each |
| believed_one_job_only | "When you uploaded it, did you think it went only to the employer you applied to?" | 0/1 |
| knows_how_to_remove | "Do you know how to take it down or make it private?" | 0/1 |
| unsolicited_contact_count | "How many times have you been contacted about jobs you did not apply for?" | number |
| suspected_fake_recruiter | "Did any of those seem fake or like a scam?" | 0/1 |
| imagined_audience_resume | "Who do you picture seeing your résumé?" | Employers only / Staffing agencies / Anyone / Government / Not sure |
| reaction_to_resume_lookup | dominant reaction when the résumé is found by a name search in the session | Surprise / Fear / Resignation / Anger / Indifference / Already knew |

## Note on the investigator's position

The investigator prepares résumés for immigrant clients in a workforce programme. Participants are recruited outside that programme, and the module is administered without advice during the session; advice on visibility settings is given in the debrief only.
